# Equipment artwork

Added 2026-09-26. Game artwork © Netmarble Corp. & Netmarble Nexus Inc.

Ring images are original embedded WebP assets from the public
[7k-combo guild page](https://7k-combo.pages.dev/g/afKyNduQ),
[asset bundle](https://7k-combo.pages.dev/assets/GuildPage-DwgC54r9.js).
Thai filenames and their aliases in `assets/7k/equip-rings/` provide exact matching
with composition notes. Original bytes are preserved; no generated artwork.
The source typo แหวนแห่งการคีนชีพ is also accepted as แหวนแห่งการคืนชีพ in the UI.

Set equipment comes from [7K Atlas](https://7katlas.com/codex.html), using
[gear-icons.js](https://7katlas.com/gear-icons.js) to resolve raid and piece paths.
Each set shows physical weapon, magic weapon, and armor as a set overview;
it does not imply the hero equips both weapon types simultaneously.
All files are local and displayed with lazy loading. Unknown equipment names
remain visible as text, and saved notes are not rewritten.
