## Original import

Retrieved 2026-09-27 from [7K Atlas Hero Codex](https://7katlas.com/codex.html), a fan reference site.
Game artwork © Netmarble Corp. & Netmarble Nexus Inc.

Metadata: [Rare](https://7katlas.com/COMBINE/heroes-R.js), [Legendary](https://7katlas.com/COMBINE/heroes-L.js), [Legendary+](https://7katlas.com/COMBINE/heroes-Lplus.js), [Legendary++](https://7katlas.com/COMBINE/heroes-Lpp.js).

`data/skills.json` maps exact catalog names to top (`s1`) and bottom (`ultimate`, Skill 2) icons.
Awakened forms use `skills`; base forms use `skills_s6` when available.
Eileene and Hayeon use awakening data, matching the existing hero presentation.
Original WebP files are preserved locally and requested lazily only when the modal opens.
Custom names without verified artwork retain text buttons. Queue data and behavior are unchanged.
