Original transparent WebP files are stored locally (about 16 KB combined).
Class glyphs are displayed in white with CSS on beveled class-colored square
badges, at the lower left above the name as in the supplied game reference.
Their transparent padding is compensated for with CSS scaling for small cards.
The awakening medal replaces the AW text at the top right, keeping the top left
available for the class icon and skill reservation marker.
