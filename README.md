# 7K Note — จดทีม Guild War

เว็บจดทีมป้องกันของศัตรู พร้อมทีมที่ใช้แก้และลำดับกดสกิล แล้วแชร์ลิงก์ให้คนในกิลด์เปิดดู หน้าจัดทีมทำให้หน้าตาเหมือนหน้า VS ในเกม

```
web/   React 19 + Vite + Tailwind v4 + React Router   → Cloudflare Pages
api/   Cloudflare Worker + Hono + D1 (SQLite)          → Cloudflare Workers
```

## รันบนเครื่อง (ต้องเปิด 2 terminal)

```bash
# terminal 1 — API
cd api
npm install
npm run db:init        # สร้างตารางใน D1 แบบ local (ทำครั้งแรกครั้งเดียว)
npm run dev            # http://localhost:8787

# terminal 2 — เว็บ
cd web
npm install
npm run dev            # http://localhost:5173  (จะส่ง /api ต่อไปที่ 8787 ให้เอง)
```

## Deploy ขึ้น Cloudflare (ฟรี)

```bash
npx wrangler login

# 1) API + ฐานข้อมูล
cd api
npx wrangler d1 create 7k-note     # ก๊อป database_id ที่ได้ไปใส่ใน wrangler.toml
npm run db:init:remote
npm run deploy                     # ได้ URL เช่น https://7k-note-api.<you>.workers.dev

# 2) เว็บ
cd ../web
echo VITE_API_URL=https://7k-note-api.<you>.workers.dev > .env.production
npm run build
npx wrangler pages deploy dist --project-name 7k-note
```
จากนั้นแก้ `ALLOWED_ORIGIN` ใน `api/wrangler.toml` ให้เป็นโดเมนเว็บ (เช่น `https://7k-note.pages.dev`) แล้วสั่ง `npm run deploy` อีกรอบ

## แผนวอร์ (หน้าแรกของกิลด์)
- 1 แผน = ประกาศ (✅ ตัวที่ OP, ❌ ชุดบ้านที่ยกเลิก) + **5 ไม้**
- แต่ละไม้: ตั้งชื่อได้ (เช่น "บ้านกันทีมที่ 1", "ไม้กายภาพ"), เลือกว่าเป็นไม้กัน/ไม้บุก
- แต่ละไม้มี **ทางเลือกหลายแบบเรียงตามลำดับ** (สูงสุด 6) — ทางเลือกหลัก → ทางเลือกสำรอง พร้อมเงื่อนไข เช่น "มีซอรัน C6" / "ถ้าไม่มี"
- โน้ตใต้ทีมพิมพ์บรรทัดละข้อ จะขึ้นเป็น ❗ ทีละบรรทัด
- ถ้าทีมไหนมีฮีโร่ครบชุดที่ยกเลิก จะขึ้นเตือนสีแดง
- จำนวนไม้แก้ได้ที่ `WAR_SLOTS` (ทั้งใน `web/src/lib/types.ts` และ `api/src/index.ts`)

## ตารางวอร์ + ประกาศ (บนสุดของหน้ากิลด์)
- ตารางรายสัปดาห์ค่าเริ่มต้น: ตี จ/พ/ส · จัดบ้านกัน อ/ศ/อา · พัก พฤ (กดไอคอนตั้งค่าเพื่อแก้)
- ปุ่ม **ประกาศ**: เลือกแผนที่ให้ใช้ + กิลด์ที่เจอ + ข้อความ (มีข้อความสำเร็จรูป เช่น "เปลี่ยนจากแผน 1 เป็นแผน 2")
- ประกาศล่าสุดที่เลือกแผนไว้ = **แผนที่ใช้อยู่ตอนนี้** (ขึ้นป้ายในหน้าแผนและรายการแผน)
- วันตีที่ยังไม่มีประกาศ จะมีข้อความเตือนคนที่มีสิทธิ์แก้ไข
- เวลาอิงเวลาไทย (Asia/Bangkok) และ**วันในเกมเปลี่ยนตอน 07:00** (ก่อน 7 โมงยังนับเป็นวันก่อนหน้า) แก้ได้ที่ `RESET_HOUR` ใน `web/src/lib/war.ts`
- **แถบประกาศติดใต้หัวเว็บทุกหน้าของกิลด์** เช็กประกาศใหม่ทุก 15 วิ (และทันทีที่กลับมาที่แท็บ) ประกาศที่ยังไม่ได้อ่านจะมีป้าย "ใหม่"

## คลังคอมพ์ (ดึงจาก 7k-combo)
ตอนแก้แผนวอร์หรือจดทีมศัตรู กด **"เลือกจากคลังคอมพ์"** แล้วเลือกทีมมาใส่ได้เลย (มีทั้งทีมกัน/บ้าน และทีมแก้ พร้อมลำดับสกิล โน้ต ของ/แหวนรายตัว)

อัปเดตคลังให้เป็นคอมพ์ล่าสุด (รันบนเครื่องตัวเอง ต้องต่อเน็ต):
```powershell
cd C:\Dev\7k-note
node scripts\import-7k-combo.mjs https://7k-combo.pages.dev/g/afKyNduQ
```
จะเขียนทับ `web/src/data/comps.json` (คลัง) และ `web/src/data/catalog.json` (รายชื่อฮีโร่/สัตว์เลี้ยงเรียงตามความนิยม) แล้ว build/deploy เว็บใหม่
เปลี่ยนลิงก์เป็นกิลด์อื่นบน 7k-combo ได้ — ข้อมูลเป็นของกิลด์เจ้าของลิงก์ ควรให้เครดิตเขา

## ระบบสิทธิ์ (ไม่ต้องสมัครสมาชิก)
- ตอนสร้างกิลด์ ระบบจะสร้าง **edit key** แล้วเก็บไว้ใน localStorage ของเครื่องนั้น (ฝั่ง server เก็บแค่ hash)
- `ลิงก์ดูอย่างเดียว` = `/g/<id>` → ใครมีลิงก์ก็เปิดดูได้
- `ลิงก์สำหรับแก้ไข` = `/g/<id>?key=...` → ส่งให้คนที่ต้องช่วยจดเท่านั้น

## จัดทีมแบบในเกม
- แถบฮีโร่/สัตว์เลี้ยงด้านล่าง: เลื่อนซ้ายขวา · กดการ์ด = ใส่ทีมที่เลือกอยู่ (กรอบประ) · ลากขึ้นไปวางช่องไหนก็ได้
- ปุ่ม ตาราง = ดูทั้งหมด · แว่นขยาย = ค้นชื่อ (ไทย/อังกฤษ มีประวัติ) · กรวย = กรองประเภท
- กดตัวละครในทีม 1 ครั้ง = เรืองแสง (เลือก) · กดซ้ำ = เอาออก · กดช่องอื่น = ย้าย/สลับ
- ขวาสุด: สัตว์เลี้ยง → วงกลมค่ายกล (พื้นฐาน/สมดุล/บุก/ป้องกัน) → วงกลมจองสกิล (ดาวสว่างตามจำนวนที่จอง สูงสุด 3)

## รูปตัวละคร / สัตว์เลี้ยง
วางไฟล์ที่ `web/src/assets/units/` ตั้งชื่อไฟล์ตามชื่อตัวละคร เช่น `ซอรัน awake.png`, `Sunran.png`, `ยอนจี.webp` เว็บจับคู่ให้เอง (ชื่ออังกฤษดู `EN_NAME` ใน heroes.ts)

## แก้รายชื่อฮีโร่ / สัตว์เลี้ยง / รูป
ไฟล์เดียว: `web/src/data/heroes.ts`
- เพิ่มฮีโร่ `{ id: 'soran', name: 'ซอรัน', type: 'attack', img: '/heroes/soran.webp' }`
- วางไฟล์รูปไว้ที่ `web/public/heroes/` (ถ้าไม่ใส่ `img` จะแสดงเป็นการ์ดตัวอักษร)
- ถ้ายังไม่มีชื่อในรายการ พิมพ์ชื่อในหน้าเลือกฮีโร่ แล้วกด "ใช้ชื่อนี้" ได้เลย
- ใส่ `awake: true` ให้ฮีโร่ที่มีร่าง awake → จะมีตัวเลือก "<ชื่อ> awake" เพิ่มให้อัตโนมัติ
- ชื่อสัตว์เลี้ยง (`PETS` ใช้ทั้งช่องหลักและช่องเสริม 4 ช่อง) และแท็กสำเร็จรูป แก้ได้ในไฟล์เดียวกัน

> รูปฮีโร่เป็นลิขสิทธิ์ของผู้พัฒนาเกม ถ้าเอาขึ้นเว็บสาธารณะ ควรทำเป็น fan project ที่ไม่หารายได้ และใส่เครดิตไว้

## โครงสร้างข้อมูล
- `guilds` → กิลด์
- `targets` → ทีมเป้าหมาย (ทีมป้องกันของศัตรู) + แท็ก + โน้ต
- `counters` → ทีมที่ใช้แก้ของแต่ละทีมเป้าหมาย + ลำดับสกิล + โน้ต
- `plans` → แผนวอร์ (5 ไม้ × ทางเลือก) เก็บเป็น JSON ก้อนเดียว

> อัปเดตจากเวอร์ชันก่อน: รัน `npm run db:init` อีกรอบเพื่อสร้างตาราง `plans` (ข้อมูลเดิมไม่หาย)

ทีมหนึ่งทีม (`Team`) มี 5 ช่อง (แถวหน้า/หลังตาม formation) ลงฮีโร่ได้สูงสุด 3 ตัว (`MAX_HEROES`) มีสัตว์เลี้ยงหลัก 1 ช่อง ช่องเสริม 4 ช่อง และค่าความเร็ว

## ไอเดียต่อยอด

- ปุ่ม 👍/👎 ให้คนในกิลด์โหวตว่าทีมแก้นี้ใช้ได้จริงไหม
- แท็บ "ทีมป้องกันของสมาชิก" เหมือนในเกม
